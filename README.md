# test-project

A small Node.js workspace for Alor. Version `1.0.0`, CommonJS, authored by Milon.

## Requirements

- Node.js
- npm

## Setup

```bash
npm install
```

This installs `dotenv` (`^18.0.8`) for loading environment variables from a `.env` file.

## Run

There is no application entry script yet. `package.json` lists `index.js` as the main file; add that file (or another script) when you are ready to run the project.

```bash
node index.js
```

Tests are not configured. `npm test` currently reports that no tests are specified.
